Настройка Windows

Установка и устранение ошибок

Для работы нужны расширение Firefox из Mozilla Add-ons и отдельное приложение TabTome для Windows.

1. Установите приложение Windows

  1. Скачайте TabTome-Setup-0.11.1.exe из GitHub Releases.
  2. Запустите установщик от текущего пользователя Windows. Права администратора не нужны.
  3. На последнем экране оставьте включённым пункт **Открыть настройки TabTome**.

Приложение устанавливается в %LOCALAPPDATA%\Programs\TabTome. Настройки и журналы хранятся отдельно в %LOCALAPPDATA%\PageToEreaderLocal.

2. Настройте почтовую доставку

  1. Укажите адрес отправителя и хотя бы один адрес доставки Kindle или PocketBook.
  2. Выберите получателя по умолчанию.
  3. В приложении Windows укажите SMTP-сервер, порт, режим TLS, имя пользователя и пароль приложения.
  4. Добавьте отправителя в список разрешённых адресов Amazon и/или белый список Send-to-PocketBook.
  5. Подтвердите только настроенные сервисы и нажмите **Сохранить и проверить SMTP**.
Gmail: используйте `smtp.gmail.com`, порт `587`, выключенный прямой TLS и пароль приложения Google. Обычный пароль от Google-аккаунта вводить нельзя.

3. Установите расширение Firefox

  1. Установите TabTome из Mozilla Add-ons.
  2. Закройте все окна Firefox и снова запустите браузер.
  3. Откройте настройки расширения. В списке готовности приложение и адреса должны быть отмечены как доступные.
  4. Один раз запустите **Проверить канал 20 МБ**. Тест не собирает книгу и не отправляет письмо.

4. Отправьте первую книгу

  1. Откройте одну или несколько статей.
  2. Откройте TabTome, отметьте вкладки и выберите Kindle или PocketBook.
  3. Оставьте пункт **Без изображений** выключенным, если картинки нужны.
  4. Нажмите **Отправить выбранное**. Для произвольного фрагмента откройте **Текст**, вставьте содержимое через `Ctrl+V` и нажмите **Отправить текст**.

Частые ошибки

Приложение TabTome не найдено

Повторно запустите актуальный установщик Windows, закройте все окна Firefox, перезапустите браузер и откройте настройки. Ручной `install-native-host.ps1` нужен только для запуска из папки с исходным кодом.

Не проходит проверка SMTP

Проверьте сервер, порт, режим TLS, имя пользователя и пароль приложения. Для Gmail убедитесь, что включена двухэтапная аутентификация и создан отдельный пароль приложения.

Письмо ушло, но книга не появилась

Проверьте, что отправитель добавлен в белый список Amazon или PocketBook, а адрес доставки введён без ошибки. После принятия письма SMTP дальнейшей доставкой управляет выбранный сервис читалки.

Есть заголовок статьи, но нет основного текста

Разметка страницы может быть непонятна Mozilla Readability. Выделите текст статьи и выберите **Отправить на читалку** в контекстном меню либо вставьте материал во вкладку **Текст**.

Где найти журнал

Откройте TabTome из меню «Пуск». Текущий журнал находится в %LOCALAPPDATA%\PageToEreaderLocal\logs\service.log. Email-адреса в нём маскируются.

Поддержка

Воспроизводимые ошибки можно отправлять через GitHub Issues. Не публикуйте адреса, пароли, содержимое страниц или полные журналы с личными данными.

TabTome не связан с Amazon, PocketBook, Mozilla или Google.
