Windows setup

Install and troubleshoot

TabTome requires the Firefox extension and the Windows app. Public download links will be connected before launch.

1. Install the Windows app

  1. Download `TabTome-Setup-0.11.1.exe` from the project's public GitHub Release.
  2. Run it as the current Windows user. Administrator rights are not required.
  3. Keep **Open TabTome settings** selected on the final installer screen.

The app is installed under %LOCALAPPDATA%\Programs\TabTome. Settings and logs are stored separately under %LOCALAPPDATA%\PageToEreaderLocal.

2. Configure email delivery

  1. Enter the sender address and at least one Kindle or PocketBook delivery address.
  2. Choose the default destination.
  3. Enter the SMTP host, port, TLS mode, username, and app password in the Windows app.
  4. Add the sender to Amazon's Approved Personal Document E-mail List and/or the Send-to-PocketBook allowlist.
  5. Confirm only the services you configured, then select **Save and test SMTP**.
Gmail: use `smtp.gmail.com`, port `587`, direct TLS off, and a Google app password. Do not enter the normal Google account password.

3. Install the Firefox extension

  1. Install the signed extension from Mozilla Add-ons.
  2. Close every Firefox window and start Firefox again.
  3. Open the extension settings. The readiness list should show the app and addresses as available.
  4. Run **Test 20 MB channel** once. The test does not build a book or send email.

4. Send a first book

  1. Open one or more articles.
  2. Open TabTome, select the tabs, and choose Kindle or PocketBook.
  3. Leave **Only text** unchecked to include images.
  4. Select **Send selected tabs**. Alternatively, open **Text**, paste content with `Ctrl+V`, and select **Send text**.

Common failures

TabTome app not found

Run the current Windows installer again, close all Firefox windows, restart Firefox, and open the settings page. Manual `install-native-host.ps1` registration is for source checkouts only.

SMTP test fails

Check the host, port, TLS mode, username, and app password. For Gmail, confirm that two-step verification and a separate app password are enabled.

The email arrives but the book does not appear

Confirm that the sender is on the Amazon or PocketBook allowlist and that the destination address is correct. Delivery after SMTP acceptance is controlled by the selected e-reader service.

An article has a title but no body

The page may use markup that Mozilla Readability cannot identify as an article. Try selecting the article text and using **Send to e-reader** from the context menu, or paste the material into **Text**.

Where to find the log

Open TabTome from the Start menu. The current log is %LOCALAPPDATA%\PageToEreaderLocal\logs\service.log. Email addresses are redacted.
