# Security model

Page to E-reader Local 0.9.0 does not listen on a TCP port. Firefox starts the registered Native Messaging host and communicates over a private stdin/stdout channel. The native application manifest allows only extension ID `page-to-ereader-local@local`; ordinary web pages and unrelated extensions cannot ask Firefox to open this channel.

`allowed_extensions` is Firefox authorization, not authentication performed by the executable itself. Any process already running as the current Windows user can directly start `PageToEreaderHost.exe`, provide framed input over stdio, read local configuration and modify the project files. This is explicitly outside the threat model; Native Messaging prevents exposure to websites and unrelated Firefox extensions, not compromise of the Windows account.

The protocol accepts only `health`, `smtp-check`, `job-status`, `settings-get`, `settings-save` and `send` commands. Input is validated, inbound frames are limited to 32 MB, outbound frames to 1 MB, articles to 25, HTML to 5 MB per article, pasted text to 1,000,000 characters, images to known JPEG/PNG/GIF signatures, and generated EPUB files to 18 MB. Plain text is XML-escaped; rich HTML is allowlist-sanitized again by the native component, and image references are rewritten to verified EPUB resources. `settings-save` accepts only two validated email addresses and the Amazon approval flag. It cannot set or read an SMTP password.

Article bodies and images are held in memory while the background task and short-lived host are running. An unfinished pasted-text draft may be stored in Firefox `storage.session`, which is memory-only, limited by this project to 8 MB and cleared when Firefox exits; oversized drafts are retained without images. The draft is removed when a text send is accepted. It is never written to the project's disk history. The extension does not request `clipboardRead`: data enters the system only through a user-initiated paste or drop into the editor, or as the selected plain text supplied by a user-invoked Firefox context-menu event. A remote image URL in pasted HTML is retained only as inert metadata; the editor does not assign it to `src` and therefore does not fetch it on paste. An explicit send downloads such images without cookies or HTTP authentication, rejects redirects and literal loopback, private, link-local, reserved and `.local` hosts. If any pasted image cannot be accepted or prepared, the UI warns before submission or aborts the send with a visible count instead of silently producing an incomplete EPUB. The eight-day disk ledger stores only job identifiers, state transitions, per-tab status, compact results and short errors. A durable `sending` marker is written before SMTP; if this write fails, SMTP is not started. An abandoned `sending` marker becomes `interrupted`, never an automatic retry.

`server\data\settings.json` stores the sender address, Send to Kindle address and the user's Amazon approval acknowledgement as plain JSON readable by the current Windows account. It contains no SMTP password. `update-project.ps1` preserves this file during upgrades.

Protocol stdout contains only length-prefixed JSON frames. Logs are written to files, rotate at 5 MB and redact email addresses and 64-character token-shaped strings. Logs must not receive article HTML or passwords.

`server\.smtp-pass` uses Windows DPAPI. It protects an offline copy from another Windows account, but the password must be decrypted into the host process memory during SMTP authentication. Decryption is lazy: `health` and `job-status` do not launch PowerShell or expose the password; `smtp-check` and `send` decrypt it into captured child-process output. DPAPI does not protect against malicious software already running as the same Windows user.

This design covers hostile web pages, unrelated extensions, accidental network exposure and offline access from another account. It does not protect a compromised Windows session, a malicious extension with the same signed ID, or a modified local project directory writable by the current user.
