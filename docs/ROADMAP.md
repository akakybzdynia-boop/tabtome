# Роадмап Page to E-reader Local

Здесь фиксируются идеи для следующих версий. Запись в роадмапе не означает, что функция уже спроектирована или запланирована к конкретному релизу.

## Версия 0.9.1 — реализовано

### Хранение SMTP-пароля только через Windows DPAPI

Открытый `SMTP_PASS` больше не является резервным режимом. Старое значение автоматически шифруется и проверяется до удаления из `.env`; ошибка или конфликт блокирует SMTP и не приводит к перезаписи секретов. Новые установки сразу создают только DPAPI-файл.

Статус: **Implemented in 0.9.1**.

## Версия 0.9.0 — реализовано

### Настройка адресов электронной почты через Firefox

Добавить в настройки расширения два поля:

1. адрес Send-to-Kindle, на который отправляется EPUB;
2. адрес отправителя SMTP — Gmail или другой совместимый почтовый адрес.

Перед реализацией нужно определить:

- где хранить адреса и как передавать их локальному компоненту;
- должна ли настройка заменять значения `KINDLE_EMAIL`, `SMTP_USER` и `SMTP_FROM` в `server\.env`;
- как проверять формат адреса и не допускать случайной отправки не тому получателю;
- нужен ли отдельный адрес `SMTP_FROM`, если он отличается от учётной записи SMTP.

Пароль приложения в настройки Firefox переносить не планируется: он должен оставаться защищённым локальным компонентом через Windows DPAPI.

Статус: **Implemented in 0.9.0**, ужесточено в **0.9.1**. Адреса хранит native host в `server\data\settings.json`; пароль допускается только под DPAPI.

### Режим «Без изображений»

Добавить пустой по умолчанию чекбокс **«Без изображений»**. Это название точнее, чем «Только текст»: форматирование, ссылки и структура документа сохраняются.

- в режиме «Вкладки» — над списком статей;
- в режиме «Текст» — над полем вставки содержимого.

Поведение:

- чекбокс выключен — отправлять текст с изображениями, как сейчас;
- чекбокс включён — не загружать, не обрабатывать и не включать изображения в EPUB;
- форматирование, ссылки и структура текста при этом сохраняются;
- выбор должен применяться ко всей текущей отправке, включая несколько вкладок.

Перед реализацией нужно решить, запоминать ли выбор между открытиями popup. Предварительно безопаснее не запоминать: каждая новая отправка по умолчанию снова включает изображения.

Статус: **Implemented in 0.9.0**. Выбор намеренно не запоминается.

### Команда в контекстном меню Firefox

Добавить пункт расширения во всплывающее меню, которое открывается правой кнопкой мыши на веб-странице.

Перед реализацией нужно определить точное действие команды:

- открыть popup расширения с уже выбранной текущей вкладкой;
- сразу отправить текущую страницу;
- отправить выделенный фрагмент страницы;
- показывать отдельные команды для страницы и выделенного текста.

Рекомендуемое название пункта: **«Отправить на Киндл»**. Команда открывает предварительно заполненный интерфейс, после чего пользователь подтверждает отправку.

Также нужно определить, должна ли команда учитывать режим **«Без изображений»** и сохранённые настройки отправки. Для реализации потребуется разрешение Firefox `contextMenus` или эквивалентное API, поэтому изменение набора разрешений нужно отдельно проверить перед публикацией.

Статус: **Implemented in 0.9.0**. Одна команда открывает popup; выделение переходит в режим текста.

### Адаптивная высота popup

Текущее состояние: ширина popup зафиксирована на `380px`, максимальная высота — `600px`, список вкладок ограничен высотой `260px` и прокручивается отдельно.

Изменить компоновку:

- при небольшом количестве вкладок popup должен занимать только необходимую высоту;
- при большом количестве вкладок popup должен увеличиваться до безопасной доступной высоты окна Firefox;
- после достижения предела список вкладок продолжает прокручиваться — показать все вкладки без прокрутки технически и визуально нецелесообразно;
- переключатель режима, поле названия и кнопка отправки должны оставаться доступными и не уходить далеко за пределы видимой области;
- при длинном списке показывать количество выбранных вкладок и, при необходимости, поиск.

Статус: **Implemented in 0.9.0**. После предела список прокручивается отдельно.

### Пошаговая первоначальная настройка

Добавить проверяемый список: адрес отправителя, адрес Send-to-Kindle, наличие защищённого пароля приложения, доступность SMTP и напоминание о списке разрешённых отправителей Amazon. Последний пункт пользователь подтверждает вручную.

Статус: **Implemented in 0.9.0**.

### Подробный прогресс и результат по вкладкам

Показывать этапы извлечения, обработки изображений, создания EPUB и SMTP-отправки. Для нескольких вкладок отображать прогресс `2 из 5` и результат каждой вкладки. Предусмотреть возможность отправить успешно обработанные статьи, если часть вкладок завершилась ошибкой.

Статус: **Implemented in 0.9.0**. Ошибка отдельной вкладки не отменяет успешно подготовленные статьи.

### Защита черновика вставленного текста

Не допускать потери большого вставленного текста при случайном закрытии popup. Предпочтительные варианты: временный черновик только в памяти сессии Firefox или отдельная страница большого редактора. Постоянное хранение тела текста на диске не планируется.

Статус: **Implemented in 0.9.0** через `browser.storage.session`, лимит 8 МБ.

### Автоматическое название и сводка перед отправкой

- предлагать название из заголовка статьи, первого заголовка вставленного текста или первой вкладки;
- перед отправкой показывать краткую сводку: получатель, название, количество статей, количество изображений и примерный размер;
- полный визуальный предпросмотр EPUB не делать без отдельного обоснования.

Статус: **Implemented in 0.9.0** в компактном виде. Размер вкладок до извлечения не оценивается, чтобы не показывать выдуманную величину.
