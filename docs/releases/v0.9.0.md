# Версия 0.9.0

Дата: 13 августа 2026 года.

## Новое

- адрес отправителя и адрес Send to Kindle настраиваются на странице расширения и сохраняются локальным компонентом;
- список готовности проверяет адреса, DPAPI-пароль, подтверждение разрешения Amazon и SMTP;
- чекбокс **Без изображений** исключает изображения из текущей отправки, не удаляя форматирование и ссылки;
- пункт контекстного меню **Отправить на Киндл** открывает popup с текущей страницей либо выделенным текстом;
- при ошибке одной вкладки остальные успешно подготовленные статьи всё равно отправляются, а результат показывается отдельно для каждой вкладки;
- незавершённый вставленный текст восстанавливается из памяти текущего сеанса Firefox;
- для длинного списка вкладок добавлены счётчик выбора, поиск и адаптивная высота;
- название книги предлагается автоматически; перед отправкой показывается краткая сводка с получателем и составом книги.

## Безопасность и совместимость

- Native Messaging protocol остаётся версии 1; host объявляет новую capability `emailSettings`;
- SMTP-пароль не передаётся расширению и остаётся в `.smtp-pass` под Windows DPAPI либо в `.env` для обратной совместимости;
- адреса и подтверждение Amazon хранятся в `server\data\settings.json`; файл сохраняется при обновлении через `update-project.ps1`;
- черновик ограничен 8 МБ, хранится в `browser.storage.session` и не попадает в дисковую историю заданий;
- добавлено разрешение Firefox `contextMenus`; разрешение `clipboardRead` по-прежнему не используется.

Обновлять расширение и локальный компонент нужно вместе до версии 0.9.0.
