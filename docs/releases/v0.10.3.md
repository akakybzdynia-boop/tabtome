# Page to E-reader Local 0.10.3

Дата подготовки: 18 августа 2026 года.

Это обновление только расширения. Приложение Page to E-reader для Windows остаётся версии 0.10.0; Native Messaging protocol остаётся версии 2. Переустанавливать приложение не требуется.

## Добавлено

- единая русско-английская сборка расширения;
- автоматический выбор языка по интерфейсу браузера;
- ручной выбор **Автоматически / Русский / English** в настройках;
- новая контрастная иконка: открытая оранжевая книга на тёмно-синем фоне;
- русская и английская политика конфиденциальности, подготовленная для публичной страницы проекта.

## Изменено

- пользовательский термин «локальный компонент» заменён понятными статусами и названием **«Приложение Page to E-reader»**;
- английская подпись режима отправки без изображений сокращена до **No images**;
- статусы, ошибки, контекстное меню, настройки и динамические результаты локализованы;
- в декларацию данных Mozilla добавлен `personallyIdentifyingInfo`, поскольку расширение передаёт установленному приложению настроенные email-адреса;
- работа в приватных окнах отключена через `incognito: not_allowed`, чтобы метаданные приватных вкладок не сохранялись в журнале заданий.

## Сборка и проверка

- исходный ZIP теперь содержит собственный `package-lock.json`;
- исходный код опубликован по Mozilla Public License 2.0; файл `LICENSE` включён в браузерные и Windows-сборки;
- воспроизведение выполняется через `npm ci` в отдельной системной временной папке;
- результаты Firefox- и Chrome-сборок сравниваются побайтно;
- SMTP-пароль по-прежнему вводится только в приложении Windows, защищается DPAPI и недоступен расширению;
- новых внешних серверов, аналитики, рекламы или телеметрии нет.

## Совместимость

- Firefox 142 или новее;
- Windows 10 1809 или новее;
- приложение Page to E-reader 0.10.0;
- Native Messaging protocol 2.
