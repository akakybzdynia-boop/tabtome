# Page to E-reader Local 0.10.2

Дата выпуска: 15 августа 2026 года.

Это срочное техническое обновление только расширения. Локальный компонент и установщик остаются версии 0.10.0; Native Messaging protocol остаётся версии 2.

## Исправлено

- Firefox popup больше не схлопывается до узкой полосы;
- удалена зависимость размера корневого элемента popup от `100vh`, которая создавала циклический расчёт высоты в настоящем Firefox;
- Firefox popup получил стабильную высоту 600 CSS-пикселей и одну вертикальную прокрутку всего содержимого;
- последняя вкладка и кнопка отправки доступны в режимах «Вкладки» и «Текст»;
- Chromium продолжает использовать собственную внутреннюю прокрутку списка вкладок.

## Совместимость

- новых разрешений расширения нет;
- формат сообщений Native Messaging не менялся;
- расширение 0.10.2 совместимо с локальным компонентом 0.10.0, переустанавливать компонент не требуется.
