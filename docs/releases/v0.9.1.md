# Page to E-reader Local 0.9.1

Дата выпуска: 13 августа 2026 года.

## Исправлено

- `SMTP_PASS` больше не используется из `.env` или переменных процесса;
- при первом запуске существующий пароль из `.env` автоматически шифруется Windows DPAPI;
- перед удалением открытой строки выполняется обратная проверка зашифрованного пароля;
- `.env` заменяется очищенной временной копией только после успешного шифрования;
- при ошибке миграции исходный `.env` сохраняется, а SMTP блокируется;
- конфликт между существующим DPAPI-паролем и значением в `.env` требует явного решения и не перезаписывается автоматически;
- `protect-smtp-password.ps1` теперь сам удаляет `SMTP_PASS` из `.env` после успешной проверки;
- новый `.env.example` больше не предлагает хранить пароль открытым текстом;
- страница настроек показывает только два штатных состояния пароля: защищён Windows или не настроен.

## Совместимость

- Native Messaging protocol остаётся версии 1;
- разрешения Firefox не изменились относительно 0.9.0;
- настройки адресов, журнал заданий и старый `.env` сохраняются обновлятором;
- существующий открытый пароль мигрируется локально и не передаётся расширению или внешним сервисам.
