# Версия 0.8.0

## Изменения

- Исправлено выравнивание чекбоксов и названий вкладок в окне расширения.
- В раздел «Текст» добавлена вставка форматированного содержимого: заголовков, абзацев, выделения, списков, цитат, ссылок, таблиц и блоков кода.
- Из вставленного содержимого можно отправлять изображения. Локальные изображения из буфера передаются напрямую, сетевые загружаются существующим конвейером обработки изображений.
- Добавлены ограничения на размер и количество вставляемых данных и двойная очистка HTML: в расширении и перед сборкой EPUB.
- Сетевые изображения не загружаются в момент вставки. При отправке они загружаются без cookies; локальные и private-network адреса блокируются, а пропущенные изображения явно показываются как ошибка.
- Для переключателя «Вкладки / Текст» добавлена навигация стрелками, Home и End.
- Добавлена собственная иконка расширения для панели Firefox.
- Локальный компонент и протокол обновлены до версии 0.8.0; добавлена возможность `pastedRichText`.

## Совместимость

Расширение 0.8.0 требует локальный компонент 0.8.0 для отправки форматированного текста. Отправка обычных вкладок остаётся совместимой с прежним протоколом, но рекомендуется обновить обе части одновременно.

## Проверка

- Полная сборка и 36 автоматических тестов сервера проходят.
- Проверены типы и контракт файлов расширения.
- Проведён автоматический запуск временного Firefox: пять строк вкладок выровнены, опасный HTML удаляется, разрешённое форматирование и изображение сохраняются.
