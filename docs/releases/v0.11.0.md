# TabTome 0.11.0

Дата подготовки: 20 августа 2026 года.

Это первый релиз под названием **TabTome**. Версии расширения и приложения Windows синхронизированы на 0.11.0. Native Messaging protocol остаётся версии 2.

## Изменено

- пользовательское название **Page to E-reader Local** заменено на **TabTome** в интерфейсе, установщике, приложении настроек, сайте и актуальной документации;
- Windows-файлы переименованы в `TabTomeHost.exe`, `TabTomeSettings.exe` и `TabTome-Setup-0.11.0.exe`;
- новая установка приложения размещается в `%LOCALAPPDATA%\Programs\TabTome`;
- метаданные EPUB теперь указывают TabTome как создателя;
- Firefox-, Chrome- и исходные release-архивы получили имена TabTome;
- метаданные Authenticode и конфигурации SignPath переведены на новое название.

## Совместимость обновления

Чтобы не разорвать связь с уже установленным расширением и не потерять настройки, сохранены:

- Firefox extension ID `page-to-ereader-local@local`;
- Native Messaging host `page_to_ereader_local` и его ключ реестра;
- Inno Setup `AppId`;
- переменные окружения `PAGE_TO_EREADER_*`;
- каталог данных `%LOCALAPPDATA%\PageToEreaderLocal`.

Старые имена в этих технических идентификаторах не являются названием продукта. Они оставлены намеренно. Установщик удаляет устаревшие имена EXE и иконки после обновления.

## Требования

- Firefox 142 или новее;
- Windows 10 1809 или новее;
- расширение TabTome 0.11.0;
- приложение TabTome 0.11.0;
- Native Messaging protocol 2.

## Обновление

1. Дождитесь завершения текущей отправки.
2. Установите `TabTome-Setup-0.11.0.exe` поверх существующей версии.
3. Установите расширение TabTome 0.11.0 и полностью перезапустите Firefox.
4. Откройте настройки расширения и выполните проверку канала 20 МБ.

Пароль SMTP, адреса Kindle/PocketBook и история заданий остаются в прежнем каталоге данных.
