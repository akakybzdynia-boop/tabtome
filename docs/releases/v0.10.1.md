# Page to E-reader Local 0.10.1

Дата выпуска: 15 августа 2026 года.

Это техническое обновление только расширения. Локальный компонент и установщик остаются версии 0.10.0; Native Messaging protocol остаётся версии 2.

## Исправлено

- Firefox больше не обрезает нижнюю часть popup в режимах «Вкладки» и «Текст»;
- весь popup в Firefox использует одну вертикальную прокрутку, поэтому последняя вкладка и кнопка отправки остаются достижимыми;
- Chromium сохраняет внутреннюю прокрутку списка вкладок и прежнее поведение popup;
- автоматический Firefox-тест проверяет 25 вкладок и оба режима при высоте окна 500 px.

## Совместимость

- новых разрешений расширения нет;
- формат сообщений Native Messaging не менялся;
- расширение 0.10.1 совместимо с локальным компонентом 0.10.0, переустанавливать компонент не требуется.

## Известная проблема

- в настоящем Firefox popup мог схлопнуться до узкой полосы из-за циклического расчёта `100vh`; исправлено в версии 0.10.2.
