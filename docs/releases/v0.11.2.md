# TabTome extension 0.11.2

Дата подготовки: 28 августа 2026 года. Публичная версия одобрена Mozilla и доступна в Firefox Add-ons.

Версия 0.11.2 переводит расширение из канала самостоятельного распространения AMO в публичный каталог Firefox Add-ons. Функциональный код совпадает с одобренной версией 0.11.1.

## Изменения

- номер расширения повышен до 0.11.2, поскольку AMO не позволяет повторно использовать номер 0.11.1 в другом канале распространения;
- функциональность, разрешения, правила обработки данных и сетевые назначения не изменены;
- совместимая версия приложения TabTome для Windows остаётся 0.11.1;
- Native Messaging protocol остаётся версии 2;
- технический Gecko ID `page-to-ereader-local@local` сохранён для обновления существующих установок.

## Обновление

[Установите расширение TabTome 0.11.2 из Firefox Add-ons](https://addons.mozilla.org/firefox/addon/tabtome/). Переустанавливать приложение TabTome 0.11.1 для Windows не требуется.
